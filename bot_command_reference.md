# Bot Command Reference Guide (v2.1)

* `/help` - Display command menu and usage instructions.
* `/plan` - Open interactive weekly training plan generator (1–7 days).
* `/today` - View today's scheduled workout session and log weights.
* `/history` - Review past workout logs.
* `/reset` - Safely clear bot state/data with an inline confirmation prompt.
* **[Photo Upload]** - Send any gym equipment photo or gallery image for automatic AI analysis, exercise generation, and YouTube verification.
